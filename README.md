# CV web · gregmaya.github.io/cv

## Publicar (una vez)
1. En GitHub crea un repositorio público llamado `cv` en la cuenta `gregmaya`.
2. Sube `index.html`, `Gregorio-Maya-CV.pdf` y `og-cv.png` a la raíz.
3. Settings → Pages → Source: "Deploy from a branch", rama `main`, carpeta `/ (root)`.
4. En uno o dos minutos queda en https://gregmaya.github.io/cv/

## Analítica (una vez)
1. Crea una cuenta en https://www.goatcounter.com con el código `gregmaya`
   (si ese código no está libre, usa otro y cámbialo en la línea `var GC = ...` de index.html).
2. Listo. Las visitas aparecen en https://gregmaya.goatcounter.com

Qué verás en el panel:
- `cv/r/k7`: visita con el código k7
- `cv/sin-codigo`: alguien entró sin código (p. ej. desde LinkedIn o escribiendo la URL)
- `pdf/r/k7`, `whatsapp/r/k7`, `email/r/k7`...: clics de esa persona
- Para cada visita: país, navegador, sistema y tamaño de pantalla

Para no contar tus propias visitas, abre una vez en cada dispositivo
https://gregmaya.github.io/cv/#toggle-goatcounter (o usa "Settings → Ignore IPs" en GoatCounter).

## Enviar
- Enlace: `https://gregmaya.github.io/cv/?r=k7`
- Usa códigos de 2–3 caracteres sin significado (k7, b2, x4) y anota en una hoja: código · persona · fecha · canal.
- Pistas de reenvío: el mismo código desde otro país, otro sistema operativo o días después.

## Actualizar el CV
- Cambias el texto en `index.html` y/o reemplazas `Gregorio-Maya-CV.pdf` por la nueva versión
  con el mismo nombre. Recuerda actualizar ambos.
- WhatsApp guarda en caché la tarjeta de vista previa. Si cambias `og-cv.png`, súbelo con otro nombre
  (p. ej. `og-cv-2.png`) y actualiza la etiqueta `og:image`.
